# Projeto Integrador (PI)

## 📌 Sobre o Projeto
Projeto acadêmico desenvolvido de forma incremental, acompanhando a evolução técnica durante o curso de Desenvolvimento de Software Multiplataforma.

## 🎯 Objetivo
Aplicar na prática os conceitos aprendidos em sala de aula, estruturando uma aplicação que evolui conforme novos conteúdos são estudados.

## 🚀 Tecnologias Utilizadas
- Java (pouco utilizado)
- Git
- HTML5
- CSS3

## 🛠 Conceitos Aplicados
- Lógica de programação
- Estruturas condicionais e de repetição
- Programação Orientada a Objetos
- Organização de código

## 📈 Evolução
O projeto está em constante evolução, com novas funcionalidades sendo implementadas conforme o avanço no curso.
O foco do projeto e torná-lo funcional para uso real. 
Os próximos passos são: melhorar  estrutura front-end para que o usuário tenha uma experiência satisfatória e adicionar um banco de dados.
